# islom-sec

Create a modern, sleek, high-tech portfolio website for a Cybersecurity Enthusiast and Junior Pentester.

Design & Aesthetic:

Dark mode aesthetic (#0d1117 background) with glowing neon green (#00ff66) or cyan accents in a Cyberpunk / Minimalist Hacker style.

Fast, fully responsive, interactive, and mobile-friendly.

Multilingual Feature (CRITICAL):

Add a functional Language Switcher (EN | RU | UZ) in the top navigation bar.

The entire website content must dynamically switch between English (EN), Russian (RU), and Uzbek (UZ) when the user clicks these buttons.

Website Sections & Content:

Hero Section: Intro phrase: 'Hi, I'm Islom — Junior Pentester & Tech Explorer'. Highlight key domains: Ethical Hacking, Web Security, AI-Assisted Development.

About Me: Passion for Cybersecurity, Strategic Thinking developed through Chess, and Analytical Skills sharpened by Tactical Gaming (CS2, RDR2).

Skills & Tech Stack:

Cybersecurity: Pentesting basics, Network Security, Web Vulnerabilities (OWASP Top 10), Linux, Bash/Python scripting.

Web & AI: AI-assisted Web Development, HTML/CSS/JS fundamentals.

Logic & Strategy: Chess strategy, Problem-solving skills.

Projects / CTF Write-ups: TryHackMe/HackTheBox walk-throughs, custom security scripts, and AI-built web applications.

Chess & Gaming Stats: Interactive links to Chess.com profile and gaming strategy highlights.

Contact: GitHub, TryHackMe profile, Telegram, Email.

Keep the overall tone professional, sharp, and confident.
